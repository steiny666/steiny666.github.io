Modding

Emulators

Nintendo

Mesen

Accurate emulator for NES and SNES games.

Platforms: Windows, Linux, macOS

snes9x

Emulator for Super Nintendo games, known for good speed and compatibility.

Platforms: Windows, Linux, macOS

simple64

Easy-to-use emulator for Nintendo 64 games, based on mupen64plus.

Platforms: Windows, Linux, macOS

mGBA

Accurate emulator for Game Boy, Game Boy Color and Game Boy Advance.

Platforms: Windows, Linux, macOS

melonDS

Emulator for Nintendo DS games, with good compatibility and speed.

Platforms: Windows, Linux, macOS

Dolphin

Emulator for GameCube and Wii games.

Platforms: Windows, Linux, macOS, Android

Azahar

Emulator for Nintendo 3DS games, based on the discontinued Citra.

Platforms: Windows, Linux, macOS, Android

Cemu

Emulator for Wii U games. The Android version is still experimental.

Platforms: Windows, Linux, Android (experimental)

Suyu

Emulator for Nintendo Switch games, continuing the yuzu project.

Platforms: Windows, Linux, macOS, Android

Eglantine

Emulator for Nintendo Switch 2 games, based on Eden.

Platforms: Windows, Linux, macOS

PlayStation

DuckStation

Emulator for PlayStation 1 games, easy to set up.

Platforms: Windows, Linux, macOS, Android

PCSX2

The best-known emulator for PlayStation 2 games.

Platforms: Windows, Linux, macOS

RPCS3

Emulator for PlayStation 3 games. Compatibility varies a lot from game to game.

Platforms: Windows, Linux, macOS

shadPS4

Emulator for PlayStation 4 games, still in early development.

Platforms: Windows, Linux

KytyPS5

Early PlayStation 5 emulator, based on Kyty. Can also run some PS4 games.

Platforms: Windows

PPSSPP

Emulator for PlayStation Portable games, runs well on PC and phones.

Platforms: Windows, Linux, macOS, Android, iOS

Vita3K

Emulator for PlayStation Vita games, still in active development.

Platforms: Windows, Linux, macOS, Android

Sega

Flycast

Emulator for Sega Dreamcast games.

Platforms: Windows, Linux, macOS, Android

RetroArch

Frontend with many cores, including Sega Saturn. Good for Saturn games.

Platforms: Windows, Linux, macOS, Android

Xbox

xemu

Emulator for the original Xbox.

Platforms: Windows, Linux, macOS

Xenia

Emulator for Xbox 360 games. Compatibility is still growing.

Platforms: Windows, Linux

PC Ports

Recomp Launcher

Website that catalogs fan-made recompiled PC ports of console games, such as N64 and GameCube titles. A dedicated launcher is still planned. You need your own legal copy of each game.

Platforms: Windows, Linux, macOS (depends on the project)
